# Змейка

Браузерная игра без внешних зависимостей. Нужны Python 3 для сервера и Node.js для тестов.

```sh
cd /workspace/game
npm start
```

Сервер слушает порт 3000. Откройте `index.html` через HTTP-сервер в браузере.
Управление: стрелки или WASD, пробел — пауза. На телефоне доступны кнопки и свайпы.
Рекорд сохраняется в браузере. После поражения нажмите «Ещё раз».

Проверка правил игры: `npm test`.

## Публикация на GitHub Pages

В настройках репозитория откройте **Settings → Pages**. В разделе
**Build and deployment** выберите **Deploy from a branch**, ветку **main**
и папку **/(root)**, затем нажмите **Save**.
После завершения публикации игра будет доступна по адресу
https://ewrydu-ops.github.io/game/.
